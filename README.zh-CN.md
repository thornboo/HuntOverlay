# PACTUM

**Pactum · 契印**

> [English](README.md) | 简体中文

一款为 **《Hunt: Showdown 1896》** 玩家打造的非官方桌面伴侣。

Pactum 是一个由社区构建、以 Windows 为首要平台的应用，计划围绕地图感知、
点位、资料信息与实用辅助功能，为猎杀过程提供支持，同时不对游戏本体进行修改。
项目将基于 Tauri 从零重构。

这个名字源自每一场猎杀背后的契约、盟约、印记与代价。**Pactum** 是正式英文名称，
**PACTUM** 是视觉字标，**契印** 是中文名称。

## 项目状态

Pactum 目前正处于 Tauri 重构的起点。活跃分支已经被有意整理为一个干净的基础，
正式应用代码尚未开始加入。

此前的 Tauri 概念验证已经证明 Windows 悬浮层方案在技术上可行。接下来的正式实现
将以 Pactum 为新的产品基础进行设计，而不是简单地给原型更换名称后继续堆叠。

## 产品方向

Pactum 希望成为一个体验统一的桌面伴侣，而不是由无关功能拼凑出的工具箱。
初步方向包括：

- Windows 悬浮层与地图辅助
- 官方点位与自定义点位相关功能
- 与实用工具自然结合的 Hunt 资料信息
- 本地优先的设置和用户数据
- 为经过谨慎选择的后续功能提供模块化基础

项目将基于 Tauri 构建，由 Rust 负责原生桌面能力，并使用专注、克制的 Web 前端
提供用户界面。

## 项目原则

- **Windows 优先：** 运行时行为以 Windows 为主要设计和验证环境。
- **不侵入游戏：** Pactum 不应修改游戏文件，不应注入游戏进程，也不应读取或修改
  游戏内存。
- **本地优先：** 设置与个人数据应尽可能由用户自己掌控。
- **克制的功能边界：** 新功能应服务于完整的伴侣体验，而不是把项目变成没有重点的
  工具集合。
- **社区构建：** 本项目是由社区独立开发的非官方项目，与 Crytek 没有从属关系。
